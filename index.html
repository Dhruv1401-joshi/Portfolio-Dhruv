About

I'm a second-year Diploma in Computer Science student, self-taught from the ground up — I started with plain HTML and CSS and worked my way to full production stacks. Somewhere along the way, client work stopped being practice and became the main event.

I run as an independent freelancer, taking projects end to end: design, frontend, backend, payments, and the admin tools an owner actually needs to run the business day to day. That means I design for people checking orders between customers, not for engineers.

Alongside client work, I go deeper on fundamentals — data structures, backend architecture, and web security — so what I ship holds up, not just looks good on day one.
